# 来源与权利

人物模型、贴图、表情和动作来自 Project SEKAI / MYSEKAI 日服资源，JP 7.0.0.15。认证缓存、账户资料和签名凭据不随成品分发。

本包使用 20 位人类角色和 6 位虚拟歌手，共 26 个身份、31 个模型。Miku 使用 121、127、128、129、130、131 六种实际存在的版本；Rin 133、Len 139、Luka 142、MEIKO 149、KAITO 155 各使用这个快照中实际可用的一种版本。31 个模型与该 JP 索引的 `mysekai/character/` 全量对应；不把全局 master 中的 56 个角色组合条目视为 56 个已存在的 MySekai 模型。完整映射见成品 `pack.json`、各主题 `source.json`。

这是非官方同人资源包。游戏人物和素材的权利属于原权利人；本项目没有将其重新许可为开放素材。

- [Clawd on Desk](https://github.com/rullerzhou-afk/clawd-on-desk)：宿主采用上游 AGPL-3.0 许可。当前版本使用未修改的锁定上游。
- [Three.js](https://github.com/mrdoob/three.js)：MIT，vendored 0.162，许可保留在 `vendor/three/LICENSE`。
- Humanoid 映射参考 [Unity Avatar bindings](https://github.com/Unity-Technologies/UnityCsReference/blob/master/Modules/Animation/ScriptBindings/Avatar.bindings.cs) 与 [ShaderMotion HumanAxes](https://gitlab.com/lox9973/ShaderMotion/-/blob/master/Script/Common/HumanAxes.cs) 所说明的轴向关系，当前项目使用自己的 Three.js 变换实现。

本项目未复制游戏中所有效果，具体见 README。
